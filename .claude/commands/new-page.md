以下の要件定義をもとに Next.js のページを実装してください。

要件定義: $ARGUMENTS

実装方針:
- CLAUDE.md のルールをすべて遵守する
- components/templates/ のレイアウトを使ってページ構造を組む
- components/patterns/ の既存コンポーネントを優先して使う
- データ取得は Server Component で行い、インタラクションのある部分のみ "use client" にする
- ページファイルは app/ 配下の適切なディレクトリに配置する
- any 型・インラインスタイル・console.log は使用しない

MDファイルで要件が渡されている場合は @ファイル名 で参照してください。
